Q: Why normalization?
A: Normalization is the process of organising the columns and tables of a relational database to reduce data redundancy and avoid update, insert and delete anomalies.

Q: What is Functional dependency?
A: A functional dependency X -> Y means that the value of attribute set X uniquely determines the value of Y.

Q: What is First normal form (1NF)?
A: A relation is in first normal form when every attribute holds only atomic values and there are no repeating groups.

Q: What is Second normal form (2NF)?
A: A relation is in second normal form when it is in 1NF and every non-prime attribute is fully functionally dependent on the whole candidate key.
